# Demos

The repository ships with local demonstrations for the brief's required behaviors:

- ambiguous interpretation,
- code retrodiction,
- JEPA-style forward prediction,
- learned transform decomposition,
- dynamic representation selection,
- neural division and reassembly,
- Olympus Forge compilation and execution,
- Hermes Nano local assistant runtime.

Run everything with:

```bash
.venv/bin/python -m olympus.cli demo run-all
```
