# Research continuity

Read `RESEARCH_STATE.json` before beginning research work, then read the dated
ledgers it references. Update the canonical state before finishing. Preserve
failed experiments, frozen protocols, negative findings, and predecessor source
identities in the append-only history; add corrections instead of rewriting them.

The current repair authorizes artificial engineering regressions. It does not
authorize protected evaluation, capability claims, scientific training, model
promotion, paid compute, or changes to recorded predecessor outcomes. New
scientific hypotheses require explicit scope, falsifiers, budgets, and a frozen
protocol before protected evidence is observed.
