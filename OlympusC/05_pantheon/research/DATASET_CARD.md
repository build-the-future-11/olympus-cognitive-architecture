# Dataset Card

## 1. Controlled synthetic benchmark

**Purpose.** Create research packages with a known adjusted treatment effect so faults can be injected with ground-truth labels.

**Generator.** `src/pantheon/package.py`. Each package has 320 rows with columns `x`, `treatment`, and `y`. The generating relation is `y = 0.8*x + 1.25*treatment + Gaussian noise` with a prespecified seed.

**Seeds used in the frozen benchmark.** 0 through 19.

**Splits.** No train/test split is used because the claim is a single OLS treatment-effect estimate on a frozen synthetic table.

**Leakage.** Not applicable to predictive generalization; the benchmark evaluates reproducibility diagnosis. Proposer results are stored separately from replicator workspaces.

**License/source.** Generated by this repository; no external data license applies.

**Fault conditions.** clean, data mismatch, metric mismatch, implementation mismatch, environment mismatch, protocol ambiguity, hidden-state contamination, and shared correlated implementation bug.

## 2. Public-data case study

**Dataset.** Breast Cancer Wisconsin (Diagnostic), using the copy bundled with scikit-learn.

**Shape.** 569 examples, 30 numeric features. Class counts: {'0': 212, '1': 357}.

**Provenance hash.** `aed4d90353a2cd2d1c1c69e013e22871c0bebe79c36adec92d0cfa6ebb8a5ddf` (semantic SHA-256 over the loaded feature matrix, labels, and feature names).

**Source metadata.** The scikit-learn dataset description identifies Dr. William H. Wolberg, W. Nick Street, and Olvi L. Mangasarian as creators and states that it is a copy of the UCI WDBC dataset. It cites Street, Wolberg & Mangasarian (1993), Mangasarian, Street & Wolberg (1995), and Wolberg, Street & Mangasarian (1994).

**Missingness.** The bundled description reports no missing attribute values.

**Evaluation protocol.** Ten prespecified stratified 75/25 train/test splits. Standardization parameters are fit on training data only.

**Caution.** This clinical-origin dataset is used only as a machine-learning reproducibility case study. The repository makes no medical or diagnostic-use claim. The current bundled description does not state a dataset license, so redistribution of a new raw-data copy is avoided; the script loads the dataset from scikit-learn at runtime.
