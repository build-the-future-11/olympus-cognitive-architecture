# Seven-model engineering completion protocol

Frozen: 2026-10-18 before implementation changes.

## Scope

This bounded repair covers the seven development-scale implementations named by
the user:

1. Hermes reference model
2. Prometheus reference model
3. Perseus reference model
4. Atlas reference model
5. Kronos reference model
6. Aion reference model
7. JEPA upscaler

It may change model input validation, padded-output behavior, engineering
inventory, artificial contract probes, documentation, tests, and receipts. It
may not perform scientific training, protected evaluation, external dataset
download, paid compute, family promotion, target-scale construction, or modify
any predecessor result.

## Engineering hypothesis

A single fail-closed seven-model contract can establish that every bounded
reference implementation is constructible, executes a finite forward path,
supports its intended gradient path, rejects ambiguous or unsafe tensor inputs,
and remains explicitly non-promoted.

## Falsifiers

The repair fails if any of the following occurs:

- the canonical inventory does not contain exactly seven unique model IDs;
- a default reference has zero parameters or cannot execute its artificial
  forward contract;
- an intended differentiable path has no finite gradient;
- non-Boolean masks, non-integral identifiers, non-floating continuous inputs,
  non-finite values, mismatched devices/dtypes, or out-of-range normalized
  images are silently admitted where the contract requires rejection;
- Kronos exposes nonzero predictions on padded trajectory steps;
- the JEPA checkpoint loader accepts the wrong expected dataset identity;
- any status output claims training-scale capability or promotion;
- prior scientific files or outcomes are changed.

## Acceptance criteria

- A typed seven-model catalog and one CLI command report all seven models.
- Deterministic artificial forward, finiteness, and backward probes pass for all
  seven without writing checkpoints or reading protected evidence.
- Adversarial unit tests cover the newly explicit admission boundaries.
- Focused tests, the complete Python suite, Ruff, and strict MyPy pass.
- The canonical research state and append-only ledger record the exact result,
  including failed verification attempts.

## Budgets

- Scientific training epochs: 0
- Protected evaluations: 0
- External downloads: 0
- Paid jobs: 0
- Model promotion actions: 0
- Artificial engineering probe examples: at most 4 per model
- Local device: CPU

## Claim boundary

Passing this protocol means `ENGINEERING_REFERENCE_COMPLETE_NOT_PROMOTED` for
the seven bounded implementations. It does not create Hermes, Prometheus,
Perseus, Atlas, Kronos, or Aion checkpoints at their target scales; it does not
establish JEPA efficacy; and it does not change the portfolio's 0/6 family
readiness or scientific dispositions.
