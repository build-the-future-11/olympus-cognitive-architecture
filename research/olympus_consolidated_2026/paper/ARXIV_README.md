# arXiv source package notes

This directory is the canonical source for the consolidated Olympus routing and
temporal-results manuscript.

Compile `main.tex` with Tectonic or a current TeX Live distribution. The source
package is intentionally self-contained: it needs only `main.tex` and
`references.bib`, and contains no proprietary records, checkpoints, generated
dataset payloads, or external images.

The paper reports five non-supporting learned-routing primaries and one supported
synthetic residual-dynamics primary. Do not retitle or summarize it as a general
validation of Olympus, learned multimodal routing, natural-data robustness,
safety efficacy, deployment readiness, or a full cognitive architecture.

Before external submission, the author must personally confirm the displayed
name and affiliation, the arXiv category and license, account ownership, and the
submission metadata. The repository artifact is prepared for submission but is
not itself evidence that an external submission occurred.
