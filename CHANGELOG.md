# Changelog

All notable changes to Olympus are recorded here.

## Unreleased

- Added the completed, independently verifiable v4 oracle diagnostic and the
  frozen v5 robust-routing/residual-temporal successor with matched controls,
  development-only selection, protected splits, checkpoint/prediction hashes,
  and fail-preserving evidence archives.
- Added a revision-pinned EditCLEVR paired-image model and five-seed protocol
  covering ID, hard, CoGenT, and no-op splits; the primary must beat the strongest
  development-selected control while satisfying an ID non-regression guard.
- Added checksummed Kaggle research runners, explicit historical-evidence
  preservation, independent bootstrap recomputation, and a root
  `RESEARCH_STATE.json` that separates implemented, executed, and supported work.
- Added optional bearer authentication and bounded concurrent workload admission
  to stateful and compute-bearing API routes.
- Added bounded, differentiable reference architectures for all six Olympus
  families: Hermes, Prometheus, Perseus, Olympus-Atlas, Kronos, and Aion. These
  remain explicitly non-promotional and are not target-scale checkpoints.
- Upgraded the JEPA upscaler to masked high-resolution subpixel targets,
  multiscale prediction, frequency/SSIM objectives and metrics, component loss
  receipts, and digest-pinned checkpoint reload.
- Added six-family CLI inventory, contract/gradient tests, updated truth
  ledgers, and an immutable engineering verification receipt.
- Added `OlympusReferenceSystem`, an auditable trainable composition with
  explicit family gates, joint coordination loss, uncertainty calibration, and
  Aion STOP enforcement.
- Expanded the composition with normalized extension channels, counterfactual
  decisions, monotone intrinsic/host risk, immutable checkpoints,
  resource-governed runtime, and finite clipped training steps.
- Added a source-disjoint, content-addressed aligned tensor dataset contract and
  CLI verification/inference entry points.
- Added multiscale and phase-aware JEPA losses plus tiled and self-ensemble
  inference.
- Added a falsifiable Olympus manuscript with matched baselines, ablations,
  statistics, data requirements, and explicit non-claim boundaries.
- Added a resource-governed composed-system training command with strict
  model/data compatibility checks, cosine scheduling, initial/final held-out
  evaluation, routing and counterfactual ablations, risk calibration and
  risk-coverage diagnostics, and immutable non-promotional reports.
- Replaced uniform JEPA tile averaging with position-aware squared-sine overlap
  blending to suppress internal seams without attenuating exterior edges.
- Hardened SFT with configuration-bound immutable run identities, strict resume
  compatibility, optimizer-step warmup and cosine decay, validation early
  stopping, and self-consistent best-state restoration.
- Trained an 884,480-parameter exploratory instruction candidate whose restored
  epoch-18 checkpoint passed the infrastructure smoke gate, then verified int4
  and int8 quality-preserving derivatives. It remains unpromoted.
- Completed the controlled-fusion v2 and reliability-supervised v3 successor
  studies without hiding their negative outcomes. Each retained 25 fitted
  checkpoints and 75 protected evaluations; both arXiv-ready packages remain
  unsubmitted and make only controlled-synthetic claims.
- Added a revision-pinned EditCLEVR upstream manifest and a fail-closed archive
  validator that checks hashes, sizes, unsafe tar members, split identity, pair
  uniqueness, and every split-referenced image, scene, and mask path.
- Completed the resource-governed EditCLEVR acquisition and admitted all five
  pinned archives: 202,835 payload files, 20,000 unique pairs, and 120,000
  validated split references with no unsafe or missing members. Admission is
  explicitly not an efficacy result or an Olympus confirmatory corpus.
- Added a 110-package universal `uv.lock`; CI and release jobs now install the
  exact locked environment and build with the locked backend rather than
  resolving dependency ranges at release time.
- Bound Python builds to the exact commit timestamp with `SOURCE_DATE_EPOCH`;
  the direct wheel and clean-sdist rebuild are byte-identical under the recorded
  110-package environment.
- Added atomic, fail-preserving EditCLEVR materialization plus stage-wise
  resource enforcement and a bounded-memory runtime loader for contained paths,
  RGB tensors, scene JSON, and no-pickle mask archives. The first complete
  materialization's 90.083% final-swap deviation remains preserved.
- Excluded external research datasets and Hub caches from Python source
  distributions after a release audit found the 186 MB split registry being
  bundled unintentionally.
- Made the top-level `olympus` API export lazy so version and package-metadata
  inspection no longer initializes FastAPI or the wider runtime dependency
  graph.
- Migrated the historical O1 preregistration from VertexED PR 653 as nine
  byte-exact, SHA-256-bound archival files with explicit unmerged provenance,
  unchanged four-arm gates, and tests that keep execution unauthorized while
  the task/provider/runtime/prompt freeze remains incomplete.

## 0.2.0 — 2026-08-22

- Added a licensed, versioned instruction-data pipeline with immutable split
  hashes, category coverage, exact/normalized deduplication, cross-split
  contamination checks, quality controls, and PII/secret rejection.
- Added real bounded causal-transformer SFT, LoRA, and nibble-packed 4-bit QLoRA
  with deterministic seeds, sequence packing, category mixing, validation,
  gradient accumulation, atomic checkpoints, adapter exports, and resume state.
- Added an exclusive RAM/swap governor, held-out category and workflow
  evaluation, int4/int8 round-trip quantization measurement, and fail-closed
  hash-bound promotion gates.
- Diagnosed the local 8B Ollama load failure and verified the recovery path with
  a 0.6B Q4_K_M baseline through the real Olympus adapter.
- Added the Hermes base-candidate decision, post-training admission gates,
  Prometheus/Perseus/Atlas/Kronos roadmaps, and a measured Foundry ledger. No
  reserved model identity was promoted.
- Expanded the release suite to 72 tests with 87.90% branch coverage.

## 0.1.0 — 2026-07-23

- Added the typed cognitive runtime, Forge compiler/runtime, LabOS portfolio
  orchestration, local memory, ingestion, retrieval, evaluation, CLI, API, and
  React web console.
- Added deterministic demonstrations and Python/web automated tests.
- Hardened HTTP ingestion with explicit network policy, HTTPS and domain
  allowlisting, public-address validation, redirect denial, content-type
  checks, and bounded response sizes.
- Replaced the web console's synthetic fallback state with live API loading,
  explicit error handling, retry support, and runtime payload validation.
- Removed aspirational application directories and unimplemented model-family
  constants, including unsupported parameter-count claims.
- Added reproducible Python and web distribution build gates.
- Added deterministic training seeds, strict dataset provenance validation,
  explicit SQLite lifecycle management, resilient SDK error handling, and an
  enforced branch-coverage threshold.
- Added continuous dependency audits, CycloneDX SBOM generation, artifact
  attestations, GitHub Releases, and PyPI Trusted Publishing automation.
- Added the durable Olympus Model Foundry: immutable dataset registration,
  experiment provenance, atomic content-addressed checkpoints, held-out baseline
  evaluation, guarded promotion, portable export, append-only evidence, restart
  recovery, and checkpoint tamper detection.
- Added a real low-cost character-language-model golden path, a stable local
  model API, Ollama discovery/generation adapter, and a live Model Foundry web
  console. The verification model is explicitly separated from Hermes claims.
